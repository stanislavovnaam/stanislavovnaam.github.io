🚀 Космическое окно

Создаём красивую программу на Python с анимацией, звёздами и прогресс-баром.

Важно: это только демонстрация. Программа не удаляет и не изменяет файлы компьютера.

Что мы создадим?

Наша программа откроет космическое окно с мерцающими звёздами. Внутри будет прогресс-бар, забавные сообщения и кнопка закрытия.

1
Создадим окно Python.
2
Добавим космический фон.
3
Нарисуем звёзды.
4
Запустим анимацию.

Как запустить проект?

  1. Установи Python 3.
  2. Создай файл с именем main.py.
  3. Скопируй в него код из этого урока.
  4. Сохрани файл.
  5. Запусти его командой:
python main.py
Чтобы закрыть полноэкранное окно, нажми Esc. Клавиша F11 отключает полноэкранный режим.

Код Python

Создай рядом с этим HTML-файлом файл main.py и вставь туда следующий код: 

import tkinter as tk
from tkinter import ttk
import random


root = tk.Tk()
root.title("Космическая проверка")

# Окно поверх других окон
root.attributes("-topmost", True)

# Полноэкранный режим
root.attributes("-fullscreen", True)

root.configure(bg="#10152f")


# Esc закрывает программу
root.bind("<Escape>", lambda event: root.destroy())

# F11 отключает полноэкранный режим
root.bind(
    "<F11>",
    lambda event: root.attributes("-fullscreen", False)
)


width = root.winfo_screenwidth()
height = root.winfo_screenheight()


# Создаём холст для рисования
canvas = tk.Canvas(
    root,
    width=width,
    height=height,
    bg="#10152f",
    highlightthickness=0
)

canvas.pack(fill="both", expand=True)


# Создаём звёзды
stars = []

for _ in range(100):
    x = random.randint(0, width)
    y = random.randint(0, height)
    size = random.choice([1, 2, 3])

    color = random.choice([
        "#ffffff",
        "#8be9fd",
        "#bd93f9",
        "#50fa7b"
    ])

    star = canvas.create_oval(
        x,
        y,
        x + size,
        y + size,
        fill=color,
        outline=""
    )

    stars.append(star)


def animate_stars():
    """Звёзды случайно меняют цвет."""

    for star in stars:
        if random.random() < 0.08:
            color = random.choice([
                "#ffffff",
                "#8be9fd",
                "#bd93f9",
                "#50fa7b"
            ])

            canvas.itemconfig(star, fill=color)

    root.after(180, animate_stars)


# Центральная панель
card = tk.Frame(
    root,
    bg="#20264d",
    padx=45,
    pady=35
)

card.place(
    relx=0.5,
    rely=0.5,
    anchor="center"
)


title = tk.Label(
    card,
    text="🚀 Запуск проверки",
    font=("Arial", 32, "bold"),
    fg="#8be9fd",
    bg="#20264d"
)

title.pack(pady=(0, 15))


subtitle = tk.Label(
    card,
    text="Ищем потерявшихся космических котиков...",
    font=("Arial", 18),
    fg="white",
    bg="#20264d"
)

subtitle.pack(pady=8)


# Настраиваем прогресс-бар
style = ttk.Style()
style.theme_use("clam")

style.configure(
    "Kids.Horizontal.TProgressbar",
    troughcolor="#10152f",
    background="#50fa7b",
    bordercolor="#10152f",
    lightcolor="#50fa7b",
    darkcolor="#50fa7b",
    thickness=25
)


progress = ttk.Progressbar(
    card,
    style="Kids.Horizontal.TProgressbar",
    orient="horizontal",
    length=500,
    mode="determinate",
    maximum=100
)

progress.pack(pady=20)
status = tk.Label(
    card,
    text="Подготовка ракеты...",
    font=("Arial", 16),
    fg="#f8f8f2",
    bg="#20264d"
)

status.pack(pady=5)


notice = tk.Label(
    card,
    text="Это демонстрация — файлы не удаляются.",
    font=("Arial", 13),
    fg="#ffcc66",
    bg="#20264d"
)

notice.pack(pady=(20, 10))


close_button = tk.Button(
    card,
    text="Закрыть",
    command=root.destroy,
    font=("Arial", 14, "bold"),
    fg="white",
    bg="#ff5555",
    activebackground="#ff7777",
    activeforeground="white",
    relief="flat",
    padx=25,
    pady=10,
    cursor="hand2"
)

close_button.pack(pady=(10, 0))


messages = [
    "Подготовка ракеты...",
    "Проверяем космический рюкзак...",
    "Считаем звёзды...",
    "Ищем потерявшихся котиков...",
    "Проверяем лунное топливо...",
    "Почти готово..."
]


def update_progress(value=0):
    if value <= 100:
        progress["value"] = value

        message_index = min(
            value // 17,
            len(messages) - 1
        )

        status.config(
            text=messages[message_index]
        )

        if value < 35:
            title.config(
                text="🚀 Запуск проверки"
            )
        elif value < 70:
            title.config(
                text="🌌 Исследуем галактику"
            )
        else:
            title.config(
                text="✨ Почти завершено"
            )

        root.after(
            80,
            update_progress,
            value + 1
        )

    else:
        title.config(
            text="🎉 Проверка завершена!"
        )

        subtitle.config(
            text="Все космические котики на месте!"
        )

        status.config(
            text="Можно продолжить приключение 🚀"
        )


animate_stars()
update_progress()

root.mainloop()

Что можно изменить?

  • Замени цвет фона в строке bg="#10152f".
  • Измени текст про космических котиков.
  • Сделай 200 звёзд вместо 100.
  • Добавь новое сообщение в список messages.
  • Измени скорость анимации в root.after(180, ...).

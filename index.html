Весёлое окно с мороженым на Python

0. Подготовка

  1. Установите Python 3.
  2. Создайте папку, например icecream_game.
  3. Скачайте картинку мороженого и назовите её icecream.png.
  4. Положите картинку в эту папку.
  5. Создайте файл icecream_game.py — сюда дети будут постепенно добавлять код.

1. Шаг 1 — подключаем модули

Что должен понять ребёнок
  • Python может подключать «дополнительные инструменты» (модули).
  • tkinter — для окон и кнопок.
  • random — для случайных чисел (чтоб окно прыгало).
  • ctypes — для работы с Windows (прячем окно из панели задач).
Что нужно написать в начале файла
import tkinter as tk
import random
import ctypes

2. Шаг 2 — список фраз и счётчик

Идея шага
  • Мы создаём список смешных фраз, которые окно будет говорить.
  • Нужен счётчик, чтобы знать, какая фраза сейчас используется.
Код для добавления после импорта
# Список шутливых фраз
NO_TEXTS = [

    "Это твой последний шанс 🍦",
    "Ну хотя бы одно маленькое!"
]

# Номер текущей фразы
current_text = 0

3. Шаг 3 — запрет закрытия крестиком и скрытие из панели задач

Идея шага
  • Когда пользователь нажимает крестик, мы не хотим, чтобы окно закрывалось.
  • Мы прячем окно из панели задач, чтобы оно было «секретным».

def on_close():
    # Ничего не делаем, чтобы окно нельзя было закрыть крестиком

3.2 Функция для скрытия из панели задач Windows

def hide_from_taskbar(win):
    """
    Прячет окно из панели задач Windows.
    """
    try:
        hwnd = ctypes.windll.user32.GetParent(win.winfo_id())
        GWL_EXSTYLE = -20
        WS_EX_TOOLWINDOW = 0x00000080
        WS_EX_APPWINDOW = 0x00040000

        style = ctypes.windll.user32.GetWindowLongW(hwnd, GWL_EXSTYLE)
        style = style | WS_EX_TOOLWINDOW
        style = style & ~WS_EX_APPWINDOW
        ctypes.windll.user32.SetWindowLongW(hwnd, GWL_EXSTYLE, style)

        # Коротко прячем окно и показываем снова, чтобы стиль применился
        win.withdraw()
        win.after(10, win.deiconify)
    except:
        # Если что-то пошло не так — просто ничего не делаем
        pass

4. Шаг 4 — движение окна и реакция на «Нет»

Идея шага
  • Мы хотим, чтобы окно прыгало по экрану.
  • Каждый раз при «Нет, не куплю» — новая фраза и новое место.

4.1 Функция движения окна

def move_popup():
    """Двигает всплывающее окно в случайное место на экране."""
    popup.update_idletasks()

    screen_w = popup.winfo_screenwidth()   # ширина экрана
    screen_h = popup.winfo_screenheight()  # высота экрана

    win_w = 520   # ширина окна
    win_h = 360   # высота окна

    max_x = max(0, screen_w - win_w)  # чтобы не вылез за край
    max_y = max(0, screen_h - win_h)

    x = random.randint(0, max_x)
    y = random.randint(0, max_y)

    popup.geometry(f"{win_w}x{win_h}+{x}+{y}")

4.2 Функция для кнопки «Нет, не куплю»

def say_no():
    """Когда нажимают «Нет, не куплю»."""
    global current_text
    current_text = (current_text + 1) % len(NO_TEXTS)
    label.config(text=NO_TEXTS[current_text])
    move_popup()

5. Шаг 5 — победа и закрытие окон

Идея шага
  • При «Хорошо, куплю» окно должно сказать «Победа!».
  • Через короткое время все окна закрываются.

5.1 Функция для кнопки «Да»

def say_yes():
    """Когда нажимают «Хорошо, куплю»."""
    label.config(
        text="Победа! 🍦\nМороженое будет куплено.\nОкна сейчас закроются."
    )
    popup.after(800, close_all)  # через 0.8 секунды вызываем закрытие

5.2 Функция полного закрытия

def close_all():
    """Закрываем всплывающее окно и главное окно."""
    popup.destroy()
    root.destroy()

6. Шаг 6 — создаём окна и кнопки

Идея шага
  • Создаём всплывающее окно с мороженым и кнопками.
  • Создаём главное окно с одной кнопкой «Показать шутку».

6.1 Функция, которая создаёт всплывающее окно

def open_popup():
    """Создаём всплывающее окно с мороженым и кнопками."""
    global popup, label, ice_image, current_text
    current_text = 0  # начинаем с первой фразы

    popup = tk.Toplevel(root)
    popup.title("Мороженое и кибер-шутка")
    popup.geometry("520x360")
    popup.resizable(False, False)
    popup.configure(bg="#fff4d6")
    popup.protocol("WM_DELETE_WINDOW", on_close)
    popup.overrideredirect(True)

    top_frame = tk.Frame(popup, bg="#fff4d6")
    top_frame.pack(pady=15)

    # Картинка мороженого или эмодзи
    try:
        ice_image = tk.PhotoImage(file="icecream.png")
        img_label = tk.Label(top_frame, image=ice_image, bg="#fff4d6")
        img_label.pack()
    except:
        tk.Label(top_frame, text="🍦", font=("Arial", 40), bg="#fff4d6").pack()

    title = tk.Label(
        popup,
        text="Пока не купишь мороженое,\nокно будет висеть 😈",
        font=("Arial", 18, "bold"),
        fg="#c62828",
        bg="#fff4d6"
    )
    title.pack(pady=(5, 10))

    # Надпись, которая будет меняться
    global label
    label = tk.Label(
        popup,
        text=NO_TEXTS[0],
        font=("Arial", 14),
        fg="#5d4037",
        bg="#fff4d6"
    )
    label.pack(pady=5)

    button_frame = tk.Frame(popup, bg="#fff4d6")
    button_frame.pack(pady=20)

    btn_yes = tk.Button(
        button_frame,
        text="Хорошо, куплю",
        width=18,
        height=2,
        command=say_yes,
        bg="#66bb6a",
        fg="white",
        activebackground="#43a047",
        activeforeground="white",
        font=("Arial", 12, "bold"),
        relief="flat"
    )
    btn_yes.grid(row=0, column=0, padx=10)

    btn_no = tk.Button(
        button_frame,
        text="Нет, не куплю",
        width=18,
        height=2,
        command=say_no,
        bg="#ef5350",
        fg="white",
        activebackground="#d32f2f",
        activeforeground="white",
        font=("Arial", 12, "bold"),
        relief="flat"
    )
    btn_no.grid(row=0, column=1, padx=10)

    popup.transient(root)
    popup.grab_set()
    popup.focus_set()

    root.after(50, hide_from_taskbar, popup)
    root.wait_window(popup)

6.2 Главное окно программы

# Главное окно
root = tk.Tk()
root.title("Главное окно")
root.geometry("340x180")
root.configure(bg="#e3f2fd")
root.overrideredirect(True)

main_label = tk.Label(

    font=("Arial", 13, "bold"),

    fg="#1565c0"
)
main_label.pack(pady=(30, 15))

open_button = tk.Button(
    root,
    text="Показать шутку",
    command=open_popup,

    height=2,
    bg="#42a5f5",
    fg="white",
    activebackground="#1e88e5",
    activeforeground="white",
    font=("Arial", 12, "bold"),
    relief="flat"
)

root.mainloop()
